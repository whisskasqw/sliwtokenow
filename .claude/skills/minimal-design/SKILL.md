# Minimal design

Основа: unslop + frontend-design. Меньше элементов, больше смысла.

## Процесс
1. Сначала понять продукт: что делает, для кого. Одна фраза.
2. Направление в пяти строках: продукт, характер (2–3 конкретных слова), мир, один яркий момент, одна фирменная деталь.
3. Токены: 4–6 цветов, шрифт, шкала размеров. Всё остальное из них.
4. Собрать, посмотреть скриншот, убрать лишнее.

## Правила
- Сетка 4px. Равные вещи — равные размеры. Группы видны по отступам.
- Одна нейтральная палитра с лёгким оттенком, три роли текста, один акцент. Акцент используется редко.
- Никаких градиентов между оттенками, свечения, цветных теней, blob-фонов, градиентного текста.
- Один яркий элемент на экран. Остальное тихое.
- Шрифт: 1 семейство (максимум 2). Веса 400 и 500. Иерархия размером и цветом. Без КАПСА и italic.
- Иконки: один набор (lucide), 16–18px, штрих 1.5. Без эмодзи в интерфейсе.
- Рамки: волосяные, 6–10% прозрачности. Радиусы вложенные: внутренний = внешний минус отступ.
- Движение: только объясняющее. Один плавный easing, 150–250ms. Без пульсаций, bounce, hover:scale.
- Мобильная версия обязательна. Видимый focus. Контраст текста от 4.5:1.

## Текст
- Коротко и конкретно. Название говорит, что это и зачем.
- Без восклицаний, приветствий, хайп-слов, выдуманных цифр и отзывов.
- Кнопка называет действие: «Сохранить», не «Отправить».
- Без точки в коротких строках.

## Запрещено
- Одинаковые карточки в ряд с одинаковой тенью.
- Центрированный шаблон «заголовок, подзаголовок, две кнопки».
- Заменять убранный декор новым декором.

## Финальный тест
Если заменить название на чужое, экран всё ещё подходит? Тогда он слишком шаблонный.
