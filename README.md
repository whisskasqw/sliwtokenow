# Фотосортер

Сайт сам раскладывает фотографии по категориям. Распознавание работает прямо в браузере (TensorFlow.js), поэтому фото никуда не отправляются.

## Категории

👤 Люди · 🐾 Животные · 🌿 Природа · 🍽️ Еда и напитки · 🏛️ Город и архитектура · 🚗 Транспорт · 💻 Техника · 📄 Документы и скриншоты · 📦 Другое

## Возможности

- Фото можно добавить кнопкой, целой папкой, перетаскиванием или вставкой из буфера (Ctrl+V).
- Автосортировка использует две нейросети: MobileNet v2 определяет сцену и объект, COCO-SSD находит людей и объекты. Скриншоты и документы определяются по «плоским» участкам изображения.
- Категорию можно сменить вручную: перетащите фото на категорию слева, либо в окне просмотра выберите её мышью или клавишами 1–9.
- Есть поиск по имени файла и распознанным меткам, а также сортировка по дате, имени и размеру.
- Результат скачивается ZIP-архивом: целиком (каждая категория в своей папке) или только текущая категория.
- Фото хранятся в IndexedDB браузера, поэтому после перезагрузки страницы ничего не пропадает.

## Запуск

Сайт статический, сборка не нужна, но открывать его нужно через веб-сервер (не через `file://`):

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Ещё его можно опубликовать на GitHub Pages: Settings → Pages → Deploy from branch.

## Структура

```
index.html            разметка
css/style.css         стили (светлая и тёмная тема, мобильная версия)
js/app.js             интерфейс: загрузка, сетка, просмотр, ZIP
js/classifier.js      распознавание и выбор категории
js/categories.js      категории и сопоставление классов ImageNet/COCO
js/db.js              хранение в IndexedDB
js/imagenet-names.js  названия 1000 классов ImageNet
vendor/               tfjs 4.22, mobilenet 2.1.1, coco-ssd 2.2.3, jszip 3.10.1
models/               веса моделей (работают офлайн)
```
